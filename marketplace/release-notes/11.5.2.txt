- We added the includeSystemAttributes parameter to the copyAttributes and Clone Java actions. When it is false, the system members __UUID__, createdDate, changedDate, owner and changedBy are not copied. When it is true, the behavior is the same as before. Note that copyAttributes never copies owner and changedBy, and Clone copies them only when withAssociations is true. (Ticket RUN-5257, GitHub issue 150)
- We added the excludeAttributes parameter to the copyAttributes and Clone Java actions. It takes a comma separated list of member names that are not copied.
- We added the DeepCloneWithSystemAttributes Java action. It works like DeepClone, but it also copies createdDate, together with __UUID__, owner and changedBy. changedDate is not preserved, because the clones are committed and a commit sets changedDate to the current time. The DeepClone Java action is unchanged.
- Existing microflows that call copyAttributes or Clone must be updated to pass the new parameters. Pass true for includeSystemAttributes and an empty value for excludeAttributes to keep the old behavior.
